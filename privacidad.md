El rincón del conocimiento (jeighost.lat) es un sitio personal de reflexiones y poemas escrito por Jeison Gonzalez. No hay cuentas de usuario, no se venden datos y no se muestra publicidad personalizada. Esta página explica, en palabras sencillas, qué información se maneja.

## Lo que se guarda en tu propio navegador

Algunas preferencias se guardan solo en tu dispositivo (almacenamiento local), nunca en un servidor:

- El tema que elegiste (oscuro o claro).
- Las reflexiones que ya leíste, para marcarlas en el índice.
- Tu decisión sobre las cookies de estadísticas.
- El nombre que usaste en tu último comentario, para no tener que escribirlo otra vez.

Puedes borrarlo cuando quieras limpiando los datos del sitio en tu navegador.

## Estadísticas (Google Analytics)

Solo si lo aceptas en el aviso de cookies, se carga Google Analytics para saber cuántas personas visitan el sitio y qué reflexiones se leen más. La dirección IP se anonimiza. Si lo rechazas, no se carga. Puedes cambiar tu decisión en cualquier momento desde «Preferencias de cookies», al final de cada página.

## Comentarios

Cuando dejas un comentario se guardan el nombre que escribas (o «Anónimo»), el texto, la fecha y el tipo de navegador. Esa información se almacena en Firebase (Google) y es pública: cualquiera que visite la reflexión puede leerla. No escribas datos personales que no quieras compartir. Si quieres que se borre un comentario tuyo, escríbeme.

## Avisos de nuevas reflexiones

Si activas los avisos, tu navegador recibe notificaciones mediante OneSignal. Solo se usa para avisarte cuando hay una reflexión nueva. Puedes desactivarlos cuando quieras desde la configuración de notificaciones de tu navegador.

## Contenido de otros servicios

- **YouTube:** los videos solo se cargan cuando pulsas reproducir, y usan el modo de privacidad mejorada de YouTube.
- **Google Fonts:** las tipografías del sitio se descargan desde los servidores de Google.
- **Alojamiento:** el sitio está publicado en GitHub Pages, que puede registrar datos técnicos básicos como la dirección IP para mantener el servicio funcionando.
- **Donaciones:** si decides apoyar el proyecto, el pago se realiza directamente en PayPal, Nequi, Daviplata o la red de criptomonedas que elijas. Este sitio no recibe ni guarda tus datos de pago.

## Menores de edad

Este sitio no está dirigido a menores de 13 años ni recoge intencionalmente información de ellos.

## Tus derechos y contacto

Puedes pedir que se consulte, corrija o elimine cualquier información tuya (por ejemplo, un comentario). Para hacerlo, escríbeme por [Facebook](https://www.facebook.com/Jeig59).

Si esta política cambia, la fecha de arriba se actualizará.
